# Derived result tables

Final aggregated outputs of the accepted pipeline run (June 2026), used directly by
the manuscript and by `figures/scripts/`. Units: climate results in kg CO2-eq
(1,000,000 kg = 1 kt as reported in the manuscript). `BAU` in file/column names is
the legacy label for the manuscript's `REF` system.

Mapping to the manuscript is given in `docs/REPRODUCING.md` (Tier 1 table).
